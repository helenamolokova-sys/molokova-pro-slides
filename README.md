# Витрина слайдов @molokova_pro

Технический репозиторий контент-завода «Молокова Pro для Instagram».

Здесь лежат отрисованные слайды каруселей — только для того, чтобы планировщик
публикаций мог забрать их по прямой ссылке. Открытым он сделан по этой причине
и ни для какой другой.

Исходники, тексты и рабочие материалы завода находятся в приватном репозитории.

Слайды складываются в `decks/<дата>/01.png … 09.png` и доступны по адресу
`https://helenamolokova-sys.github.io/molokova-pro-slides/decks/<дата>/01.png`.

Неподтверждённые черновики удаляются.
